ModelHub 與 Amazon SageMaker

TrustForge 不只使用 AWS 提供的基礎模型。我們另外建立自己的訓練、校準與治理流程，並可選擇 ModelHub 或 Amazon SageMaker 作為訓練後端。

TrustForge 自有能力自行定義訓練資料、校準方法、品質門檻、候選版本及人工核准規則。
兩種訓練後端ModelHub 是我們整合的訓練平台；Amazon SageMaker 是可替換的 AWS 管理式訓練服務。

我們自行訓練的是什麼？

TrustForge 自行訓練的是信心校準模型，不是重新訓練 Amazon Bedrock 的大型語言模型。Bedrock 負責主張抽取與報告敘事；校準模型則把 raw confidence 修正為更接近歷史真實表現的 calibrated confidence。

為什麼要自己訓練模型？

更即時市場結構、消息來源與操縱手法持續改變，最新資料能讓校準基準跟上現在。
更適合任務通用基礎模型不知道 TrustForge 的 Evidence、來源可靠度與信心定義；自有模型可針對任務最佳化。
更可解釋每次訓練都有資料版本、時間範圍、指標、artifact 與 SHA-256，可追查信心如何改變。
形成資料護城河累積「什麼來源在什麼情境下可靠」的時間序列經驗，這是單純呼叫外部模型無法取得的能力。
降低平台綁定統一 TrainingBackend 介面可在 ModelHub 與 SageMaker 間切換，上層流程不必重寫。
安全地持續改善新模型只會成為候選；未通過 holdout 比較與人工核准，就不能進入正式環境。

與 AWS 基礎模型的關係

競賽中的生成式 AI 推理仍使用 Amazon Bedrock 提供的 AWS 基礎模型。TrustForge 自行訓練的校準模型位於不同層級：它不生成市場文章，而是校正信心並支援信任治理。因此，使用 Bedrock 與自行訓練模型可以同時存在。

正確說法：TrustForge 擁有自己的模型訓練、校準與治理流程，並支援 ModelHub 與 Amazon SageMaker 兩種訓練後端。Amazon SageMaker 是 AWS 服務，不應稱為「我們自己的 SageMaker」；我們自己掌握的是資料、方法、品質 Gate、模型產物與啟用決策。
