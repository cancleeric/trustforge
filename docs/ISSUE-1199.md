# feat: 點點新手引導彈出視窗 — 首次進入教學流程

## 目標

首次進入 TrustForge 時彈出歡迎視窗，由點點引導新手了解系統。操作者可選擇「需要說明」或「跳過」。

## 流程

```
用戶打開首頁
  → 彈出歡迎視窗（半透明遮罩 + 中央卡片）
  → 卡片上方：點點頭像（日常表情 $$ 眼微笑 + 點頭動畫）
  → 卡片內容：「嗨！我是點點，歡迎來到 TrustForge！需要我帶你認識一下嗎？」
  → 兩個按鈕：【好的，帶我看看】/【我自己逛就好】

用戶按【好的，帶我看看】
  → 點點切換為日常表情
  → 進入 3~5 步教學流程（見下方）

用戶按【我自己逛就好】
  → 關閉視窗，記住選擇（localStorage 或 cookie），下次不再彈出
```

## 點點自我介紹（第一步固定文字）

> 「我是 TrustForge 的 AI 分析助手——點點！
> 我的工作是幫你從各種來源中篩選出值得信任的資訊。
> 接下來我會帶你了解怎麼使用這個系統，很簡單的！」

## 新手教學步驟（3~5 步卡片）

| 步驟 | 點點說 | 畫面提示 |
|------|--------|----------|
| 1 | 「先選一個你想看的幣種，點它就好！」 | 高亮星系中的幣種行星 |
| 2 | 「按下分析，我就會去幫你蒐集多個來源的消息並打信任分數」 | 高亮分析按鈕 |
| 3 | 「這裡的數字是信任分——0.8 以上很可信、0.3 以下要小心」 | 高亮信任分數區域 |
| 4 | 「每個結論都可以點開看原始出處，不信的話自己驗證！」 | 高亮證據展開區 |
| 5 | 「好了！有問題隨時看右下角找我。祝分析愉快！」 | 點點揮手（可選動畫） |

每步之間有「下一步 →」按鈕，最後一步是「開始使用！」。

## 點點在視窗中的呈現

- 位置：卡片上方或左側，頭像 80x80px
- 表情：日常（$$ 眼微笑 + 點頭動畫）
- 對話泡泡：每步的文字放在泡泡框裡，看起來像點點在說話
- 步驟切換時加一個短暫的「思考」表情（閉眼 0.5 秒）再切回日常

## 技術規格

### 元件

新建 `frontend/src/components/DiandianOnboarding.tsx`

### 狀態管理

```ts
// 是否顯示 onboarding
const showOnboarding = !localStorage.getItem('diandian_onboarding_done')

// 用戶選擇跳過或完成後
localStorage.setItem('diandian_onboarding_done', '1')
```

注意：TrustForge 目前禁用 localStorage 存敏感資訊，但 onboarding 偏好不含機密，
可以用 localStorage。如果要維持一致性改用 SameSite cookie 也可（參考現有 locale cookie 做法）。

### 樣式

- 遮罩：`background: rgba(0,0,0,0.6); backdrop-filter: blur(4px)`
- 卡片：深色主題一致（`background: rgba(6,12,22,0.95); border: 1px solid rgba(77,216,224,0.3)`）
- 點點頭像帶光暈效果
- 響應式：手機上卡片佔滿寬度，頭像縮小到 56px

### 觸發位置

在 `HermesDashboard.tsx` 或 `App.tsx` 的最外層 mount 時檢查是否需要顯示。
