## Lessons Learned

1. **Build includes trustforge_core**: The initial artifact build omitted
   `src/trustforge_core/`. The original `deploy_ec2.sh` copies `src/trustforge`
   but current code also depends on `src/trustforge_core/`. Future builds must
   include both.

2. **Python version**: AL2023 default Python 3.9 lacks `StrEnum`. Production
   runs older code (v0.16.18) that doesn't need it. New code requires Python
   3.11+. Drill used Python 3.12. Consider adding `strEnum` compatibility shim
   or upgrading production Python.

3. **kernel.py is not in active import chain**: Moving `trustforge/trust/kernel.py`
   did not break the service. The active kernel is `trustforge_core/`. The
   regression injection target should be `trustforge_core/__init__.py`.
   Drill plan should be updated to specify the correct file.

4. **SSM command quoting**: JSON parameter escaping for SSM commands requires
   careful handling of single quotes, dollar signs, and shell metacharacters.
   Recommend using simple one-line commands without process substitution.
