## 命題
- 類別：智慧交易。主題：**加密市場分析 AI Agent：多源資訊的信任提煉**。
- 重點**非**單篇新聞摘要、**非**單純技術指標回測；要求：真正多源整合、有層次推理（事實→推論→結論）、對不確定性的清醒判斷、超越表面的分析角度。
- 比賽當日從題目池抽 1 題 + 指定幣種，現場公布，無法預知。

## 參賽作品應展現的 5 能力
1. **多源資料整合**：價格/鏈上/新聞/官方公告/社群情緒/總經等，非單一文章摘要。
2. **有層次推理**：清楚區分事實/推論/結論，說明證據如何支撐判斷。
3. **不確定性與限制說明**：資料不足/訊號矛盾/來源可信度有限時，明確指出限制，不硬給結論。
4. **可回溯證據管理**：關鍵結論可回溯至具體來源（來源網址、取得時間、引用片段）。
5. **具洞察分析角度**：跨源連結、反方證據、風險因子、非顯而易見脈絡。

## 題目模板（至少含）
1. 市場判斷 2. 關鍵依據（來源+時間+解釋）3. 信心說明（含已知限制）
正反方/風險不確定性/後續觀察不強制，但納入推理品質與完整度觀察。

## 範例題型
- 一｜多源整合：分析【幣種】過去兩週，整合價格/鏈上活躍/新聞/社群熱度，給整體狀態 + 各類資料一致程度。
- 二｜假設驗證：對「【幣種】短期盤整」蒐集正反證據，說明最終判斷與理由。
- 三｜比較分析：比較【幣種A】vs【幣種B】市場位置與風險特徵（流動性/關注度/風險敞口）。

## 幣種池
**BTC / ETH / SOL / BNB / XRP**

## 提交項目（4 件）
1. **Final Report**（主要評分對象；格式自由 Markdown/PDF/HTML/Dashboard）
2. **Evidence List**（支撐結論的來源；JSON/CSV/表格）
3. **Execution Log**（時間戳+主要工具呼叫+資料取得紀錄+分析流程摘要）
4. **Source / Config**（Agent 程式碼+設定+執行說明）

### Report 至少含：1.結論/市場判斷 2.關鍵依據（對應 Evidence，說明如何支撐）3.信心說明（信心/已知限制/可能推翻結論的條件）
### 每筆 Evidence 至少含：`source`、`fetched_at`、`content_reference`、`related_claim`（網頁類建議附 source_url + 引用片段；API/CSV/鏈上類需 endpoint/參數/時間範圍/交易對/地址/query 名/檔名等可回溯資訊）。主辦方會**抽查** Evidence 的可回溯性、引用真實性、證據↔結論對應。

## 資料
- 主辦提供共同基準：**BTC/ETH/SOL/BNB/XRP 近五年 Daily OHLCV CSV**（欄位 `date,open,high,low,close,volume`；UTC 日期；價格單位以資料包標示）。
- 其餘新聞/公告/鏈上/社群/總經/政策監管等**參賽者自取**。可用：公開 API（CoinGecko/CryptoCompare/交易所）、公開新聞、公開社群（Reddit/X/官方）、鏈上（Etherscan/Solscan/Dune）、付費資料（需揭露、不得為唯一關鍵依據）。
- **可用自備 API key** 存取公開/付費資料來源，**包含…模型推理服務**（付費/商業 API 需揭露來源/時間/引用）。
- **反作弊鐵則**：外部服務可做取得/檢索/整理/輔助，但**不得把第三方已產出的完整市場判斷/交易訊號/買賣建議/投資分析報告當主要結果直接提交**。核心判斷、推理鏈、最終報告須由**參賽者自設計 Agent 流程產生**，能說明資料如何整合/取捨/推論。
- 評分觀察：來源多樣性、來源獨立性（避免單一來源/同文重複）、是否過度依賴分析師文章而缺自行推理交叉驗證、關鍵結論可回溯。

## 評分標準
- **15% 創意度**：原創分析方法/資料使用/Agent 設計；非表面化非摘要的市場洞察。
- **20% 技術可行性**：可運行 Agent 架構（蒐集/工具調用/整理/推理/報告/執行紀錄）；**若使用 AWS 服務或其他 Agent framework**，需合理架構+穩定執行。
- **25% 商業應用性**：解決資訊分散/雜訊/判斷不透明；可讀性、可採信性，協助使用者更有效率地理解市場狀況。
- **30% 主題切合度**：切合主題；多源整合/證據回溯/矛盾訊號處理/信心校準/限制說明。**若高度依賴單一第三方分析服務結論、缺自有 Agent 流程/證據整合/推理，扣此項。**
- **10% 完成度**：功能完整（輸入題目幣種→完成分析→產出報告/Evidence/Log/程式碼）；Demo 清楚穩定。
- **加分 +10%：採用 AWS Kiro 作為 AI 整合開發環境（IDE）工具。**
