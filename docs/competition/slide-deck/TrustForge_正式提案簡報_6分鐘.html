05OWN CALIBRATION MODEL

我們自行訓練的，是信心校準模型

不是重造大型語言模型，而是用歷史判斷與後續結果校正「這次應該相信多少」。

WHY

跟上市場變化

固定規則無法反映來源與操縱手法的變化；自有資料形成任務專屬基準。

HOW

時間切分與校準

時間點資料接回後續結果；Isotonic Regression 將 raw confidence 校準。

CONTROL

候選不能自動上線

資料 Gate、產物驗證、版本紀錄與人工核准；automatic_apply=false。

正式競賽採 AWS 合規路徑：SageMaker 可執行訓練；ModelHub 是專案已有的替代訓練／治理整合，不是正式15分鐘執行的外部依賴。
自有資料 · 自有校準方法 · AWS 合規執行5 / 8
2:50–3:45｜我們自己掌握資料、校準方法、品質 Gate 與啟用決策。ModelHub 與 SageMaker 都已有程式介面，但競賽正式流程應留在 AWS 允許服務內。
