07INFORMATION SECURITY

可信分析先保護資料、模型與執行權限

01

最小權限

IAM Role 分離服務權限；SSM 管理機密，不把 Key 放進 Repo。

02

網路隔離

nginx 提供 HTTPS；Python API 僅監聽 loopback，不直接暴露。

03

產物完整性

S3 不可變產物、SHA-256、版本 manifest 與可回滾 release。

04

成本與稽核

Bedrock 預算上限、run_id、Execution Log、CloudWatch 與人工核准。

Fail closed：權限、資料或模型狀態不可信，就不假裝成功。
