第 1 頁｜0:00–0:35

市場不缺 AI 答案，缺的是值得相信的判斷

各位評審好，我們是 Team 11 中再參與。加密市場每天都有新聞、社群、鏈上與監管資訊，但資訊越多，不代表判斷越可靠。一般 AI 可以快速整理內容，卻很難回答三個問題：這個來源可信嗎？它是不是同一篇消息的重複轉載？什麼證據會推翻現在的結論？因此，我們提出 TrustForge Hermes：先提煉信任，再生成分析。
開場後停頓一秒，再切到第 2 頁。
第 2 頁｜0:35–1:20

為什麼要蒐集資料，也為什麼要自行訓練

市場每天都在變，固定規則容易把昨天的可信度帶進今天。所以我們持續蒐集最新的市場、鏈上、新聞、官方與社群資料，讓分析跟得上現在。同時，我們會把當時的判斷接回後續真實結果，訓練 TrustForge 自己的信心校準模型。它不是另一個大型語言模型，而是用來校正：當系統說有八成信心時，歷史上是否真的有接近八成可靠。
我們的目標，是用最新資訊提升即時性，用歷史真相提升完整性，再用校準避免 AI 過度自信。
第 3 頁｜1:20–2:05

六類資料互相驗證

TrustForge 整合六類資料。第一是 HOYA BIT 與 OHLCV 市場行情；第二是 Etherscan、Whale Alert 等鏈上活動；第三是公開新聞與 RSS；第四是專案官方公告、SEC 與臺灣監管來源；第五是 Reddit 等公開社群情緒；第六是 CoinGecko、DefiLlama、CMC 等基本面與生態指標。
我們不追求來源越多越好，而是要求來源類型互補、彼此獨立。每筆資料都保存來源、取得時間、查詢條件與引用片段；來源失敗或資料不足，也會直接揭露。
指向投影片上的六類資料卡片，不逐字念英文服務名稱。
第 4 頁｜2:05–2:50

核心技術是生成前的 Trust Layer

資料進來後，第一步先拆成可驗證的 Claim，為每個主張建立 claim_id。第二步由 Trust Kernel 評估來源聲譽、獨立佐證、時效與風險訊號。第三步保留支持與矛盾證據，分開顯示方向判斷與資訊完整度。最後才交由 Amazon Bedrock 組織成可讀報告，而且只能依 claim_id 對應已驗證證據。
因此，Bedrock 負責語意與敘事；TrustForge 自己掌握信任計算、證據契約與限制。這就是我們和一般 RAG 最大的差別。
第 5 頁｜2:50–3:40

ModelHub／Amazon SageMaker 如何支援自行訓練

我們自行訓練的是 TrustForge 信心校準模型。訓練資料會保留當時可見資訊，再接回 T+7 等後續真實結果，避免偷看未來；接著使用 Isotonic Regression，將原始信心校準為更接近歷史命中率的信心。
ModelHub 與 Amazon SageMaker 是可替換的訓練後端：負責觸發訓練、取得模型 artifact，以及保存資料版本與 SHA-256。ModelHub 是我們整合的模型訓練與治理平台；SageMaker 是 AWS 的管理式訓練服務。新模型只能成為候選版本，必須通過資料 Gate、holdout 比較與人工核准，不能自動取代正式版本。
這一頁是新增重點。一定要講清楚「自行訓練校準模型，不是自行訓練 LLM」。
第 6 頁｜3:40–4:25

一次正式執行，四份交付物同步抽查

現場輸入指定幣種、題型與題目後，TrustForge 會在十五分鐘限制內產出四項交付。第一是 Final Report，包含判斷、依據、信心與限制；第二是 Evidence List，保存來源、時間、引用與對應主張；第三是 Execution Log，記錄每一步工具、模型、成本與時間；第四是 Source／Config，提供原始碼、設定與重現方式。
評審可以任選一條結論，從 claim_id 回到 Evidence，再用 Execution Log 確認這次分析真的用了什麼資料與模型。
第 7 頁｜4:25–5:15

資訊安全不是附加功能，而是可信 AI 的前提

TrustForge 從四個層面保護資料、模型與執行權限。第一，IAM 採最小權限，機密由 SSM 管理，不把 API Key 放進 GitHub。第二，nginx 對外提供 HTTPS，Python API 只監聽 loopback。第三，模型與交付物使用 S3 不可變產物、SHA-256 與版本 manifest，發生問題可以回滾。第四，Bedrock 設有成本上限，每次執行都有 run_id、Execution Log 與 CloudWatch 紀錄。
我們採用 fail closed：權限、資料或模型狀態不可信，就停止或明確降級，不會假裝成功。
第 8 頁｜5:15–6:00

HOYA BIT 得到的是可治理的市場判斷

對 HOYA BIT 而言，TrustForge 帶來三層價值。第一，最新多源資料讓分析跟上市場變化；第二，每句判斷都能回到來源，降低研究與查核成本；第三，自行訓練的校準模型會持續改善信心品質，但仍由品質 Gate 與人工核准守住正式版本。
我們不承諾預測幣價，也不替使用者做投資決定。我們交付的是一個更即時、更完整，而且經得起追問的答案。市場不缺 AI 答案；TrustForge 補上答案背後的證據與信任。謝謝各位。
最後一句放慢，說完停頓，不再補充。

快速備詢提醒

Q：你們自行訓練的是什麼？
A：是信心校準模型，不是大型語言模型。它利用歷史判斷與後續真實結果，修正系統的信心。
Q：ModelHub 和 SageMaker 有什麼不同？
A：兩者都是可替換的訓練後端。ModelHub 是我們整合的模型訓練與治理平台；Amazon SageMaker 是 AWS 管理式訓練服務。
Q：為什麼不能讓模型自動更新？
A：自動更新可能造成效能退化、資料污染或不可追責。所有候選模型都必須通過資料 Gate、holdout 評估與人工核准。
Q：Bedrock 在系統裡負責什麼？
A：負責主張抽取、有限語意分類與報告敘事；信任分數、證據關係與限制由 TrustForge 控制。
