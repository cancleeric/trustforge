## 共通狀態語意

| 狀態 | 語意 |
|---|---|
| 已實作 | 有可定位證據，且已完成適用的核准與有效性驗證 |
| 部分實作 | 有部分可定位事實，但介面、核准或有效性驗證尚未完成 |
| 僅計劃 | 尚無實作證據，不得推論控制存在 |
| 不適用 | 已記錄範圍判定及理由，且由有權者核准 |

競賽符合性與 AIMS 改善是不同追溯軸；前者不得作為 ISO/IEC 42001 認證證據。
