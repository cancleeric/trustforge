# AIMS support controls

Status: **draft / unapproved / non-effective**

This directory defines the support-control evidence expected for TrustForge. It
does not claim ISO/IEC 42001 certification or that a control is operating merely
because a document exists.

## Required state vocabulary

Use only `planned`, `completed`, or `verified` for training. `completed` requires
a dated attendance record; `verified` additionally requires evidence that the
learning objective was assessed. Unknown facts remain `TBD` and are not inferred.

## Evidence set

- `competency-and-training-register.md`: role requirements, gaps, actions, owners,
  review dates, and training evidence.
- `document-and-communication-control.md`: lifecycle, retention, access, obsolete
  handling, communication approval, and evidence URI rules.

Approval requires Product, Security, and Compliance review. Public statements
about certification, compliance, conformity, or regulatory status require
Compliance approval before publication.
