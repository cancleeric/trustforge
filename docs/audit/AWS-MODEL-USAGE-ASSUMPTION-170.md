# AWS Model 使用限制——已記錄合規假設（#170）

## 時效窗口

2026-07-13 工作坊現場詢問 Mars Li 的機會已過（PLAN-round-20260720-sprint.md 已標「已過時效窗口」）。

## 事實背景

主辦方規則對 AWS model 的使用限制有兩種可能的解讀：

1. **嚴格解讀**：只能使用 AWS 官方管道（主辦方提供的帳號與 Bedrock 額度）。
2. **寬鬆解讀**：允許自備 API key（例如直接走 Anthropic/OpenAI 官方渠道）。

## 正式假設

**無論上述哪一種解讀成立，TrustForge 目前的 Bedrock-only 接入方式皆合規。**

理由：
- 當前架構**只透過 AWS Bedrock 官方 SDK 呼叫模型**，完全未注入任何外部（非 AWS）API key。
- 若嚴格解讀成立 → 我們「只用 AWS 官方管道」，合規。
- 若寬鬆解讀成立 → 我們也未使用外部 key，自然合規。
- 兩種解讀的交集 = Bedrock-only 是安全的 default。

## 限制與影響

- 本假設不構成對主辦方規則的法律解釋，僅供團隊內部決策參考。
- 若後續取得 Mars Li 或主辦方的權威答覆，本文件應更新為該答覆的引用紀錄。
- 未來若因商業考量需改為「自備 key + 繞過 Bedrock」，則必須重新評估合規性。
