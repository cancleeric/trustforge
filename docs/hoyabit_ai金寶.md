## 核心技術架構

### 1. Agentic AI 自主規劃架構
具備任務拆解、工具調用與動態反思能力，從「回答問題」升級為「規劃並執行金融操作流程」，重構交易互動方式。

### 2. 多模型協作與 LLM Gateway 調度
依任務階段動態調度不同模型，兼顧推理深度、生成品質與成本效率，確保系統穩定且可持續擴張。

### 3. 金融級風險分級與 Human-in-the-Loop
每筆金融操作皆經風險評分與授權分級設計，高風險情境保留人工審核，建立 AI 與人協作的安全決策機制。

### 四階段方法論

| 階段 | 內容 |
|------|------|
| **1. 場景共創** | 聚焦高價值流程，定義使用者旅程、例外情境與成效指標 |
| **2. 流程智能化** | 讓 AI 能追問、判斷、呼叫工具、生成建議並觸發後續作業 |
| **3. 治理內建化** | 把資料遮罩、政策規則、權限檢查、日誌稽核寫進流程 |
| **4. 成果營運化** | 用儀表板追蹤使用率、節省工時、轉換率與風險事件 |

### 核心原則
- 作為應用與治理底層，支援提示詞優化、代理編排、權限與審計
- 導入不需換掉既有核心系統，而是在既有架構外建立可控的 AI 控制層
- 交付的是「**能力平台 + 場景成果**」，不是單一聊天機器人
- 訓練未來擴充多模型、多部門、多場景
